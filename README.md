# LLM vs PLS for Polysulfone Membrane Mechanical Property Prediction


[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.11](https://img.shields.io/badge/Python-3.11-blue.svg)](https://www.python.org/)

> **Paper:** Cao, D.; Chan, M. K.\*; Yeo, W. S.; Bey, S.; Figoli, A. *Intelligent Materials Modelling: Large Language Models Versus Partial Least Squares Regression for Predicting Polysulfone Membrane Mechanical Performance.*

---

## Overview

This repository provides the **complete data, code, and prompt templates** for reproducing the results reported in the above manuscript. The study benchmarks knowledge-driven inference using four large language models (LLMs) against a data-driven partial least squares (PLS) regression baseline for predicting the mechanical properties of polysulfone (PSF) membranes under extreme data scarcity (*n* = 10).


### Key Findings

- **Elongation at break (EL):** LLMs achieved statistically significant improvements, with DeepSeek-R1 and GPT-5 delivering ~40% RMSE reductions over PLS. Mean absolute errors decreased from 11.63 ± 5.34% (PLS) to 5.18 ± 0.17% (GPT-5).
- **Young's modulus (E) and tensile strength (TS):** Statistical parity between LLMs and PLS (*q* ≥ 0.05), indicating PLS remains competitive for properties with strong linear structure–property correlations.
- **Run-to-run variability:** LLM predictions showed SD ≤ 3%, compared to up to 47% for PLS on challenging folds.

### Requirements

```
Python >= 3.11
numpy >= 1.26.4
scipy >= 1.11.4
pandas >= 2.2.2
scikit-learn >= 1.4.2
matplotlib >= 3.8.4
seaborn >= 0.13
```

### Install dependencies

```bash
pip install numpy scipy pandas scikit-learn matplotlib seaborn
```

### Run PLS baseline

```bash
python PLS_bootstrap_LOOCV.py
```

This will generate all CSV data files and PNG figures in the working directory. Expected runtime: < 1 minute on a standard laptop.

### Run LLM inference

1. Open `prompts/Prompt_Folds_1-10.md`.
2. For each fold (1–10) and each run (1–5):
   - Copy the prompt text block into a **new, isolated** chat session with the target LLM.
   - Replace `LLM_Name` with the actual model name (e.g., `DeepSeek-R1`).
   - Replace `run=1` with the current run number.
   - Record the CSV output.
3. Aggregate all outputs into `results/llm/<model_name>/`.

> **Note:** LLM inference requires API access or web interface access to the respective models. The raw prediction CSVs from our experiments are provided in `results/llm/` for direct analysis.

## Output Files

### PLS outputs (generated by `PLS_bootstrap_LOOCV.py`)

| File | Description |
|------|-------------|
| `run_level_metrics.csv` | Per-run RMSE, MAE, R² for each target |
| `predictions_runs_long.csv` | Long-format predictions (property × run × sample) |
| `predictions_runs_wide.csv` | Wide-format predictions (one column per run) |
| `predictions_summary_by_sample.csv` | Sample-level predicted mean ± SD |
| `vip_by_run.csv` | Variable Importance in Projection per run |
| `coefs_by_run.csv` | Standardized regression coefficients per run |

### Figures (generated by `PLS_bootstrap_LOOCV.py`)

| Figure | Description |
|--------|-------------|
| `errorbar_E/TS/EL.png` | Sample-level predicted mean ± SD vs actual |
| `parity_E/TS/EL.png` | Parity plots with linear fit and R² |
| `parity_runs_E/TS/EL.png` | Multi-run overlay parity plots |
| `residuals_hist_E/TS/EL.png` | Residual distributions (histogram + KDE) |
| `residuals_vs_pred_E/TS/EL.png` | Residual vs predicted (heteroscedasticity check) |
| `bland_altman_E/TS/EL.png` | Bland–Altman agreement analysis |
| `components_heatmap_E/TS/EL.png` | Optimal *k* selection heatmap per fold × run |
| `vip_E/TS/EL.png` | VIP bar charts (cross-run mean ± SD) |
| `coef_E/TS/EL.png` | Standardized coefficient bar charts |
